GitHub Actions가 매일 미국 재무부/FRED·OECD·미국 연방준비제도 이사회 데이터를 확인하고, 수집 성공 시 JSON을 갱신합니다. 일반 지표 차트는 방문 시 저장된 JSON을 읽습니다.

신용위험 지표인 GZ 스프레드와 EBP, 경기침체 모형 확률은 미국 연방준비제도 이사회 공개 CSV에서 수집합니다. 6개 시계열만 직접 저장하고, ICE BofA의 제한된 하이일드·CCC 시계열은 제외했습니다.

미국 선행지수는 OECD CLI이며 Conference Board의 LEI가 아닙니다. 12개월 경기침체 확률은 연준 연구모형의 산출값이며 연준의 공식 전망이 아닙니다. AI 종합의견은 최초 1회 생성한 시점의 자료에 한정되며 매일 자동 재생성하지 않습니다.

갱신 실패 시 이전 데이터가 남을 수 있으므로 사이트 갱신일과 각 지표의 실제 관측일을 모두 표시합니다.
