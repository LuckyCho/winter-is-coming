TRANSPARENT BY DESIGN

데이터를 어떻게 다루나요?

GitHub Actions가 매일 FRED·미국 재무부 및 OECD의 공개 데이터를 확인하고, 수집 성공 시 JSON을 갱신합니다. 일반 지표 차트는 방문 시 저장된 JSON을 읽습니다.

하이일드·CCC 이하 신용스프레드는 ICE Data Indices, LLC 자료를 FRED의 공식 삽입 그래프로 표시합니다. 이 차트는 방문 시 FRED에서 직접 불러오며 저작권 보호 시계열을 GitHub에 재배포하지 않습니다. FRED에서 제공하는 최근 3년 자료만 표시되므로 상단의 1·3·5·10년 선택과 별도로 동작합니다.

미국 선행지수는 OECD CLI이며 Conference Board의 LEI와 다른 지표입니다. 본 페이지는 비상업적 정보 관찰용입니다.

갱신 실패 시 이전 데이터가 남을 수 있으므로 사이트 갱신일과 각 지표의 실제 관측일을 모두 표시합니다.
